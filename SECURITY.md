# Security

This public repository must contain only the auditable LUNA|SHOP demonstration
launcher and its informational page.

- Never commit credentials, tokens, cookies, private keys, account data,
  customer data, payment data, or private storefront source.
- The launcher must only open the HTTPS storefront and must never request
  elevation or collect authentication and payment information.
- Report suspected exposure privately to the repository owner rather than in a
  public issue.
